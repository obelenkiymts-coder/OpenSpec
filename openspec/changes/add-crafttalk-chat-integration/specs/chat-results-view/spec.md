# Spec Delta: chat-results-view

## Purpose

Отображение результатов чата в существующем UI АРМ Коллектор: результаты бота в карточке/истории заёмщика и вкладка «Чаты» с данными от бота для бизнес-представителей. Без операторской функциональности (этап 2).

## ADDED Requirements

### Requirement: Результаты бота в карточке и истории заёмщика
Результаты чата от бота — зафиксированное обещание оплаты и факт контакта — SHALL отображаться операторам в существующей карточке/истории заёмщика без разработки новых экранов.

#### Scenario: Оператор видит обещание из чата
- **WHEN** оператор открывает карточку клиента, получившего обещание через чат
- **THEN** обещание оплаты отображается в существующей карточке/истории заёмщика

#### Scenario: Оператор видит факт контакта из чата
- **WHEN** оператор открывает карточку клиента, с которым был эффективный диалог в чате
- **THEN** факт успешного контакта отображается в существующей карточке/истории заёмщика

### Requirement: Вкладка «Чаты» с данными от бота
UI АРМ Коллектор SHALL предоставлять вкладку «Чаты», отображающую информацию от бота (диалоги/результаты) в таком же виде, как в РФ. Доступ MUST предоставляться бизнес-представителям (продуктовая группа) на просмотр. На старте вкладка SHALL показывать только результаты бота: статусы от операторов не отображаются, поскольку операторы чата не подключены.

#### Scenario: Бизнес-представитель просматривает диалоги
- **WHEN** пользователь с правом просмотра открывает вкладку «Чаты»
- **THEN** он видит диалоги и результаты, переданные ботом

#### Scenario: Доступ без права просмотра
- **WHEN** пользователь без права просмотра вкладки «Чаты» запрашивает её
- **THEN** доступ запрещён
