# Spec Delta: crafttalk-agent-api

## Purpose

Поперечная рамка доступа чат-платформы CraftTalk к АРМ Коллектор: авторизация пользователя-бота, идемпотентность методов агентов, стандартные коды ошибок и аварийное отключение чата. Все методы агентов (верификация, обещание оплаты, регистрация контакта) наследуют эти требования.

## ADDED Requirements

### Requirement: Доступ CraftTalk под пользователем-ботом
CraftTalk SHALL обращаться к АРМ Коллектор по API под отдельной учётной записью бота с секретом, хранящимся на стороне АРМ Коллектор. Учётной записи бота MUST быть запрещён доступ к UI АРМ Коллектор.

#### Scenario: Успешный вызов метода агента
- **WHEN** CraftTalk вызывает любой метод агентов с валидными учётными данными бота
- **THEN** запрос авторизуется и обрабатывается как обычный вызов API

#### Scenario: Вызов с недействительным секретом
- **WHEN** запрос к методам агентов приходит с отсутствующим или неверным секретом
- **THEN** запрос отклоняется с ошибкой авторизации, данные не возвращаются

#### Scenario: Попытка входа бота в UI
- **WHEN** учётная запись бота используется для доступа к UI АРМ Коллектор
- **THEN** доступ запрещён

### Requirement: Идемпотентность методов агентов
Все методы агентов CraftTalk SHALL быть идемпотентными и безопасными к повторным вызовам: повторная верификация и повторная фиксация обещания MUST не создавать дубликатов и не искажать состояние.

#### Scenario: Повторный вызов с теми же параметрами
- **WHEN** CraftTalk повторно вызывает метод агента с теми же параметрами после уже обработанного запроса
- **THEN** результат согласован с первым вызовом и дубликат состояния не создаётся

### Requirement: Стандартные коды ошибок методов агентов
Ошибки методов агентов SHALL возвращаться по стандарту сервиса: 1 — внутренняя ошибка; 2 — сервис недоступен; 3 — некорректные значения параметров; 4 — заёмщик/займ не найдены; 12 — операция не может быть выполнена.

#### Scenario: Некорректные параметры запроса
- **WHEN** метод агента вызывается с некорректными значениями параметров
- **THEN** возвращается код ошибки 3 с описанием, состояние не меняется

#### Scenario: Внутренняя ошибка при обработке
- **WHEN** обработка запроса агента прерывается внутренней ошибкой
- **THEN** возвращается код ошибки 1, состояние не меняется

### Requirement: Аварийное отключение чата
АРМ Коллектор SHALL предоставлять тогл аварийного отключения чата, управляемый дежурными/ОПС без выпуска релиза. При включённом тогле все методы агентов CraftTalk MUST переставать отвечать успешно (недоступность), чтобы CraftTalk показывал клиентам сценарий ошибки «сервис недоступен, обратитесь позже». Действие тогла MUST быть обратимым.

#### Scenario: Тогл включён при инциденте
- **WHEN** дежурный включает тогл аварийного отключения
- **THEN** все методы агентов отвечают «сервис недоступен» и CraftTalk ведёт клиента по сценарию ошибки

#### Scenario: Тогл выключен после инцидента
- **WHEN** дежурный выключает тогл аварийного отключения
- **THEN** методы агентов снова обрабатывают запросы без выпуска релиза

### Requirement: Сохранение совместимости REST API v1.1
Действующие методы REST API v1.1 АРМ Коллектор SHALL не изменяться назад несовместимым образом; новые методы агентов MUST публиковаться отдельной версией со своей спецификацией.

#### Scenario: Существующие потребители v1.1
- **WHEN** после внедрения методов агентов существующий клиент вызывает метод API v1.1
- **THEN** поведение и контракты v1.1 не изменились
