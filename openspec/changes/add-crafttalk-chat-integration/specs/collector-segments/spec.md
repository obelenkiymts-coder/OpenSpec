# Spec Delta: collector-segments

## Purpose

Настраиваемые правила сегментации клиентов по параметрам займа/просрочки: расчёт номера сегмента при верификации для выбора ветки сценария бота и страница управления правилами в UI АРМ Коллектор.

## ADDED Requirements

### Requirement: Настраиваемые правила сегментов
Система SHALL поддерживать настраиваемые правила сегментации: каждое правило сопоставляет параметры займа/просрочки (сумма, срок, глубина просрочки и т.п.) номеру сегмента и имеет приоритет применения.

#### Scenario: Займ подпадает под правило
- **WHEN** параметры займа клиента удовлетворяют условиям правила
- **THEN** клиенту назначается сегмент этого правила

#### Scenario: Изменение правила применяется к последующим расчётам
- **WHEN** продуктовая группа изменяет или добавляет правило сегментации
- **THEN** при следующем расчёте сегмента применяется обновлённый набор правил без выпуска релиза

### Requirement: Расчёт сегмента при верификации
При верификации система SHALL применять правила сегментации к параметрам займов клиента и возвращать номер сегмента в RAW-массиве.

#### Scenario: Верифицированный клиент получает сегмент
- **WHEN** верификация клиента завершена успешно и у клиента есть займы
- **THEN** RAW-массив содержит номер сегмента, рассчитанный по правилам

### Requirement: Страница управления сегментами в UI
UI АРМ Коллектор SHALL предоставлять страницу управления сегментами: список правил, их параметры и приоритеты. Доступ к странице MUST быть ограничен ролями, которым делегировано управление (продуктовая группа).

#### Scenario: Управление правилами продуктовой группой
- **WHEN** авторизованный пользователь с правом управления открывает страницу сегментов
- **THEN** он видит список правил с параметрами и приоритетами и может их изменять

#### Scenario: Доступ без права управления
- **WHEN** пользователь без права управления сегментами запрашивает страницу
- **THEN** доступ запрещён
